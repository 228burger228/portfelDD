## 🛠 Технические особенности реализации
* **Figma-Inspired Light Aesthetics**: чистая светлая дизайн-система, выверенные отступы, контрастная типографика Inter и пастельные бейджи.
* **High-Performance Scroll Pipeline**: оптимизированный цикл на базе `requestAnimationFrame` с кэшированием геометрии секций — без layout thrashing и микрофризов.
* **Accessible Modals**: модальные окна с фиксацией фокуса (focus trap), закрытием по `Escape`, сохранением позиции скролла и sticky-кнопкой закрытия.
* **Official Recommendation Letter**: просмотр оригинала официального благодарственного письма с печатью и подписью.
* **Direct Lead Generation**: интерактивные теги-пресеты, копирование никнейма Telegram в один клик и интеграция студийного бота [@dmitryB_studio_bot](https://t.me/dmitryB_studio_bot).
